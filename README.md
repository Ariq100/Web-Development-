# 🌱 Web Dev Journey

This repository documents my journey learning web development — from writing my very first lines of HTML and CSS, all the way to building modern interfaces with **React (Vite)**, **JavaScript**, **Tailwind CSS**, and **DaisyUI**.

I started this repo as a personal practice space, and it's grown into a timeline of how my skills (and code quality 😅) have evolved over time. If you're also learning web dev, feel free to poke around, use it as a reference, or follow a similar path.

---

## 🗺️ The Journey

| Stage | Skills / Tools | What I Was Learning |
|-------|----------------|----------------------|
| 1️⃣ Basics | HTML, CSS | Semantic markup, the box model, flexbox, basic responsive design |
| 2️⃣ Interactivity | JavaScript | DOM manipulation, events, basic logic, fetch/APIs |
| 3️⃣ Modern Tooling | React + Vite | Components, props, state, hooks, build tooling |
| 4️⃣ Styling at Scale | Tailwind CSS | Utility-first CSS, responsive design, custom themes |
| 5️⃣ UI Components | DaisyUI | Prebuilt component libraries on top of Tailwind |

Each stage generally lives in its own folder (see [Project Structure](#-project-structure)) so you can see exactly how a plain HTML/CSS page differs from a fully componentized React + Tailwind + DaisyUI app.

## 🚀 Getting Started

Most of the early projects (HTML/CSS/JS) can be run by simply opening the `index.html` file in your browser.

For the React + Vite projects:

```bash
# Navigate into the project folder
cd 03-react-vite/your-project-name

# Install dependencies
npm install

# Run the dev server
npm run dev
```
